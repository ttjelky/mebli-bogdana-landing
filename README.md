# Меблі від Богдана — демо-лендинг

Демо-сайт для салону меблів «Меблі від Богдана» (Чернівці).

Без збирання: `index.html` + `css/custom.css` + `js/main.js`. Bootstrap 5 (`css/bootstrap.min.css`, MIT) — лише сітка й reset, шрифт Inter (Google Fonts), іконки Font Awesome (CDN).

Дизайн: світлий теплий фон, білі картки, чорні кнопки-пігулки, помаранч `#e8772e` і графіт `#2c3036` з логотипа «МБ» — як акценти. Секції: hero з фото, каталог 6 категорій, переваги, «На замовлення» (4 кроки), 3 відгуки з Google, форма прорахунку + контакти + карта, підвал. Адаптив перевірено на 1440, 820 і 390 px; на телефоні меню-бургер і липка панель «Подзвонити / Прорахунок».

## Що в демо тимчасове

1. **Фото** — безкоштовні з Unsplash. Попросити в клієнта фото його робіт (у Instagram-профілі їх багато) і покласти в `img/`.
2. **Форма** — лише показує «Дякуємо». Для робочої версії — Telegram-бот (окрема послуга) або Formspree.
3. **Кроки «На замовлення»** — загальні формулювання; уточнити, чи є безкоштовні заміри, терміни виготовлення, гарантія.
4. Слово «Демо-сайт» у підвалі — прибрати перед здачею.
